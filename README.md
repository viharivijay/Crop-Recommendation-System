# 🌱 Crop Recommendation System

An AI-powered **Crop Recommendation System** that recommends the most suitable crop based on soil and environmental conditions. The system uses **Machine Learning** to analyze agricultural parameters and provides intelligent crop recommendations through a user-friendly **Flask web application**.

The project also includes **Explainable AI (XAI)** for understanding model predictions and **Kannada language translation** to make the system more accessible to local farmers and Kannada-speaking users.

---

##  Project Overview

Selecting the right crop is an important decision in agriculture. Crop selection depends on several factors such as:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* Soil pH
* Rainfall

This project uses Machine Learning to learn patterns from agricultural data and recommend the most appropriate crop based on these input parameters.

##  Key Features

###  Crop Recommendation

Predicts a suitable crop based on user-provided agricultural parameters.

###  Machine Learning

Uses a trained Machine Learning classification model to generate crop recommendations.

###  Explainable AI

Uses **SHAP (SHapley Additive exPlanations)** to help understand how different features influence the model's prediction.

###  Flask Web Application

Provides a simple web interface where users can enter agricultural parameters and receive recommendations.

Uses Python-based data processing and analysis techniques to prepare agricultural datasets for Machine Learning.

##  Explainable AI with SHAP

The project uses **SHAP** to improve the interpretability of Machine Learning predictions.

Instead of only providing a crop prediction, SHAP can help explain how input features contributed to the prediction.

For example:

```text
Prediction: Rice

Important Features:
- Rainfall
- Humidity
- Temperature
- Nitrogen
- Soil pH
```

This makes the Machine Learning model more understandable and transparent.
