About AgroXAI

Empowering Agriculture Through Artificial Intelligence

About Our Project

AgroXAI is an AI-powered Crop Recommendation System developed to help farmers select suitable crops based on soil nutrients and climatic conditions.

Our Objective

Our objective is to support smart and sustainable agriculture using Machine Learning and data-driven agricultural recommendations.

Technologies Used

  • Python
  • Flask
  • Machine Learning
  • HTML, CSS and Bootstrap
  • Natural Language Processing
  • Kannada Language Translation

Key Features

  • AI-based Crop Recommendation
  • Crop Disease Information
  • Weather-Based Advisory
  • Agricultural Market Price Analysis
  • Government Scheme Information
  • Kannada Translation Support
